# Original save route evidence

`[benchmark.routes.save_controls]` declares one original `POST /vms/{id}/save`
case through service UDS and authenticated gateway. Counts2/quick1,240s total
deadline,30s exec timeout,1MiB response budget,2vCPU/1GiB resources, exact name
and bounded marker belong to config. Mutations are finite, never read-load loops.

Reuse the canonical isolated lifecycle/local image owners. Create explicitly
ephemeral without a name; named create is already persistent and cannot stand
in for this transition. Existing readiness defaults still require persistence;
only this preparation explicitly requests ephemeral readiness. Original mapped
workload execution writes known workspace bytes, independently downloaded through
normal public file admission. A VM runtime marker and kernel boot ID establish
the pre-stop runtime. No registry seeding or borrowed VM is used.

One original save claims the configured name. Independently require the same
public VM ID, original process creation identity, unchanged publication generation,
live session directory and directory inode. Moving/replacing a session under
the live process, a second persistent directory or JSON success without an actual
named persistent public state all fail. Original workspace bytes remain readable.
Publication generation is the exact decimal-string listener identity, distinct
from UUID-shaped boot IDs and browser-request spawn IDs.

Raw header/first-body/complete clocks time only the original save HTTP request.
Verified completion includes independent live-claim/identity/byte checks. Mandatory
subsequent normal stop/cold-start retention checks are outside those clocks, while
the existing process-tree resource/wall phase includes the whole cycle.

Stop must exit the original process and retain the same named persistent ID in
Stopped/resumable state. Canonical session path must relocate from sessions to
persistent only after exit, preserving directory device/inode and retiring the
old path. Normal start must retain that ID/name/path/bytes but use a new process,
new publication generation and new kernel boot ID; transient /run marker must
be absent. Namespace-scoped workload and separate public download verify exact
retained bytes. This proves cold persistence, not a warm snapshot/resume.

Finally normal stop and delete independently remove the exact owned path/public
identity/process. Original mutations are never replayed after ambiguous errors;
the existing isolated service fixture owns failure cleanup. The only policy
exception admits export of the exact synthetic proof filename. Existing strict
Transport/Cycle/raw/resource/Rust statistics/store/fitness owners are unchanged;
no DB/projection, public API, credential or new driver authority is introduced.
Source tests use explicit effect doubles and launch no VM. Actual coherent native
execution and fit repeated measurements remain parent-owned before any speed or
all-endpoint completion claim.
