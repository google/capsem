# Original corporate policy reload

`[benchmark.routes.reload_controls]` declares finite block-original and
restore-original cases for POST /corp/reload over service UDS and authenticated
gateway. The existing isolated lifecycle/image/mock fixture boots one real
pinned-reference workload; no source URL, user home, credentials or seeded
publication acknowledgement is used.

The fixture snapshots exact local settings/corporate/source-file bytes,
permissions and absence, and first proves that its known original HTTP flow
reaches the mock. Outside the request clock it appends one narrow private block
rule to the isolated corporate file. Reload must return success and exactly one
reloaded owner. The shipping handler counts an owner only after process applies
the exact active-policy bytes, proxy applies the same digest, and broker
publication acknowledges the same original generation. No accepted/file-only
response is enough: the original process/publication identity must remain live,
the bounded active artifact must contain the block, and a new original HTTP flow
must be403 with no independent mock delivery. No response is its own effect oracle.

Original input bytes and permissions are then restored outside the request clock.
A second original reload must acknowledge one owner, restore byte-identical
active policy and deliver exactly one known HTTP request/response to the mock.
The existing owner cleanup removes the disposable VM. On failure, input files
are still restored and the existing fixture stops remaining processes; this
file restoration alone never certifies an effective runtime reload.

Strict request header/first-body/complete receipts measure the one original
reload HTTP request without retries. Separate verified-completion clocks include
original owner/artifact/effective-traffic checks. Preparation and file edits are
outside request clocks; the existing resource phase spans full lifecycle. Cases
never enter read-load loops. Config owns cycles, deadlines and response/log/policy
bounds; canonical Rust stats/raw/fitness/store owners remain unchanged.

Source doubles/adversaries prove collector logic, not native measurements.
Managed lease narrowing/relaxation, invalid-policy fail-closed retirement and
physical policy/approval audit remain canonical acceptance/state proof, never
inferred from this normal-workload flow. Exact matching-cohort execution and fit
repeats are still required for performance claims.
