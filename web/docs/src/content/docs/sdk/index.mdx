This guide introduces the Python, TypeScript, and Rust SDKs through a small
example that creates a VM and runs a command. Choose a language below for its
installation requirements, example, and explanation of the result.

The API references describe Capsem 0.7.1. The TypeScript example works with the
published npm SDK 0.7.0; until the Python and Rust 0.7.1 packages are published,
their installation instructions use the matching source revision.
