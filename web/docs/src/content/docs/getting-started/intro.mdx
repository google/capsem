Capsem runs AI agents and tools from container images inside isolated Linux
VMs on your computer. It provides a security layer for inspecting requests,
applying access rules, and recording activity.

Like Docker, Capsem runs as a service that you can control from command-line
tools or code. Use it for interactive work through the terminal interface
(TUI) or graphical Capsem UI, or integrate it into your own product and
evaluation workflows with the Python, TypeScript, or Rust SDK.

## Install Capsem

[Install Capsem](/getting-started/installation/) on your computer first.
Installation sets up the service, command-line tools, and Capsem UI.

## Choose how to use it

After installation, choose your use case:

- **Work interactively:** [create a VM and access it through the TUI or Capsem UI](/getting-started/how-to-use-capsem/) to run your agent and work with its files.
- **Automate evaluations or integrate into a product:** [create a VM and run commands with the SDK](/sdk/), then [integrate VM workflows into your application](/guides/developers/integrate-the-sdk/).
- **Deploy for an organization:** [manage policy, credentials, and images for your team](/guides/enterprise/deploy-capsem/).
