---
title: Configure security through the Capsem UI
description: How do I inspect and change security permissions in the Capsem UI?
---

This page describes the planned workflow for inspecting and changing VM security
permissions through the Capsem UI. The complete UI for reviewing effective
permissions, changing allowed access, and verifying the result is not available
yet; use the rule-file guides linked below for current configuration.

The guide will cover destination/tool permissions, credential grants,
administrator-locked controls, validation errors, and checking the resulting
decision. Screenshots and steps will be added from the implemented controls.

Today, configure rules through
[Enforce security policy](/guides/enterprise/enforce-security-policy/).
Use [Configuration reference](/reference/configuration/) for file ownership
and precedence.
